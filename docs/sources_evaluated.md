# Оценка источников (sources_evaluated.md)

Критерии оценки (по ТЗ):
1. **Частота публикаций** — Высокая (ежедневно/несколько раз в неделю), Средняя (еженедельно), Низкая (реже раза в неделю/нерегулярно).
2. **RSS/API** — есть ли официальный RSS/API или только парсинг/скрейпинг.
3. **Язык** — РФ/EN.
4. **Тип источника** — СМИ, корпоративный (блог вендора), блог/ниша, сообщество, исследование, Telegram-канал.
5. **Качество контента** — факты, ссылки на первоисточники, аналитика (Высокое/Среднее/Низкое).
6. **Риск paywall/ограничений** — Нет/Частично/Высокий.

Итоговая оценка = сочетание всех критериев с весом на частоту + RSS/API (обязательные для MVP) и тематическое покрытие.
