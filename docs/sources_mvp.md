## Проверка обязательных критериев

- **RSS или API есть у 9 из 11** источников (кроме двух Telegram-каналов, которые парсятся через Telegram API/Telethon, и AI Drip, где придётся парсить архив рассылки). *Обновление по факту реализации (этап 2): VC.ru пришлось отключить — общий RSS сайта не содержит статей раздела /ai, отдельного RSS у раздела нет. Работающих RSS-источников на практике — 7 (из 8, где VC.ru был восьмым).*
- **Частота не реже раза в неделю** — выполняется у всех источников, кроме отключённого VC.ru.
- **Тематическое покрытие** — на каждую из 5 тем приходится 2-5 источников, кроме «Работа/заработок с AI»: после отключения VC.ru там остался только Habr (см. риск Р4 в PLAN.md).
- **Языковой баланс** — из русскоязычных активно работают Habr и 2 Telegram-канала (VC.ru отключён), 7 источников на английском.

## Статус реализации

MVP задеплоен и работает: 1 октября 2026 сделан первый настоящий запуск из GitHub Actions (не `dry_run`) — дайджест из 25 новостей по всем 7 рабочим RSS-источникам и 2 Telegram-каналам успешно собран, отправлен в 3 частях и помечен как отправленный; `digest.db` обновлён и закоммичен обратно в репозиторий. Дальше бот работает по расписанию самостоятельно (понедельник 7:00 Europe/Istanbul) — согласно `TECH_SPEC.md` (раздел 7), MVP считается окончательно принятым после 2–3 недель подряд без вмешательства Галины.

Реальные рабочие адреса для Cursor и TechCrunch отличались от изначально предполагаемых — уточнены и обновлены в таблице выше.
